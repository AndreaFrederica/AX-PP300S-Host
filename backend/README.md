# AX PP300 串口通信协议

> 说明：以下所有数据均为 **16 进制**

---

## 1. 数据发送格式（6 字节）

| 字节 | 1    | 2        | 3          | 4          | 5            | 6    |
|------|------|----------|------------|------------|--------------|------|
| 名称 | 帧头 | 标识帧   | 数据低八位 | 数据高八位 | 校验位       | 帧尾 |
| 值   | `A5` | `0x00`   | `0x00`     | `0x00`     | 计算值       | `5A` |

- **校验位** = `标识帧 + 数据低八位 + 数据高八位` 后对 **256 取余**（即低八位）。

> 发送所有设置数据后，设备都会回传 `0x01`。如果没有收到，表示没有发送成功。

---

## 2. 标识帧定义

### 2.1 数字 / 曲线界面

| 标识帧 | 含义             | 单位   | 数据范围 | 备注                          |
|--------|------------------|--------|----------|-------------------------------|
| `0x00` | 设置电压 / VSET  | 10 mV  | 0–3000   |                               |
| `0x01` | 设置电流 / ISET  | 10 mA  | 0–1010   |                               |
| `0x02` | 过压保护 / OVP   | 10 mV  | 0–3050   |                               |
| `0x03` | 过流保护 / OCP   | 10 mA  | 0–1050   |                               |
| `0x04` | 延时输出 / DELAY | S      | 0–9999   |                               |
| `0x05` | 开关翻转 / REV   | S      | 0–9999   |                               |
| `0x06` | 过功率保护 / OPP | 10 W   | 0–30     | OPP = 数据 × 10 + 10 W        |
| `0x07` | 过温保护 / OTP   | 10 ℃   | 6–10     |                               |
| `0x08` | 输出开关 / ONOFF | —      | 0 / 1    | 0 = 关闭输出，1 = 打开输出    |

### 2.2 中文界面 — 参数列表 0

| 标识帧 | 含义     | 单位   | 数据范围 | 备注                                              |
|--------|----------|--------|----------|---------------------------------------------------|
| `0x09` | 参数列表 | —      | 0–4      | 选择参数列表                                      |
| `0x0A` | 设置电压 | 10 mV  | 0–3000   |                                                   |
| `0x0B` | 设置电流 | 10 mA  | 0–1010   |                                                   |
| `0x0C` | 过压保护 | 10 mV  | 0–3050   |                                                   |
| `0x0D` | 过流保护 | 10 mA  | 0–1050   |                                                   |
| `0x0E` | 关断电流 | 10 mA  | 0–1000   |                                                   |
| `0x0F` | 关断时间 | S      | 0–99     | 低八位 = 数据，高八位 = 单位（0=秒，1=分，2=时） |

### 2.3 中文界面 — 参数列表 1 ~ 4

参数列表 1 使用标识帧 `0x1A` ~ `0x1F`，参数列表 2 使用 `0x2A` ~ `0x2F`，参数列表 3 使用 `0x3A` ~ `0x3F`，参数列表 4 使用 `0x4A` ~ `0x4F`。含义与参数列表 0 完全一致。

### 2.4 数据查询

| 标识帧 | 含义     | 备注       |
|--------|----------|------------|
| `0xFF` | 数据查询 | 所有界面通用 |

## 3. 数据查询回传格式（15 字节）

**示例帧：**

```
A5 88 13 00 00 00 00 B4 07 25 01 00 01 7D 5A
```

| 字节 | 名称           | 说明                                              |
|------|----------------|---------------------------------------------------|
| 1    | 帧头           | `A5`                                              |
| 2    | 电压低八位     | 单位 **1 mV**                                     |
| 3    | 电压高八位     |                                                   |
| 4    | 电流低八位     | 单位 **1 mA**                                     |
| 5    | 电流高八位     |                                                   |
| 6    | 功率低八位     | 单位 **10 mW**                                    |
| 7    | 功率高八位     |                                                   |
| 8    | 输入电压低八位 | 单位 **0.01 V**                                   |
| 9    | 输入电压高八位 |                                                   |
| 10   | 温度低八位     | 单位 **0.1 ℃**                                    |
| 11   | 温度高八位     |                                                   |
| 12   | 恒压/恒流模式  | `00` = 恒压（CV），`01` = 恒流（CC）              |
| 13   | 输出开关状态   | `00` = 关闭，`01` = 打开                          |
| 14   | 校验位         | `(字节2 + 字节3 + … + 字节13) % 256`              |
| 15   | 帧尾           | `5A`                                              |

### 3.1 示例解析

**示例数据：** `A5 88 13 00 00 00 00 B4 07 25 01 00 01 7D 5A`

- 输出电压：`0x1388` = **5000** → **5.000 V**
- 输出电流：`0x0000` = **0** → **0.000 A**
- 输出功率：`0x0000` = **0** → **0.00 W**
- 输入电压：`0x07B4` = **1972** → **19.72 V**
- 温度：`0x0125` = **293** → **29.3 ℃**
- 模式：`00` → **恒压（CV）**
- 输出开关：`01` → **打开**

## 4. 发送示例

| 示例 | 发送数据                          | 含义                                                |
|------|-----------------------------------|-----------------------------------------------------|
| 例 2 | `A5 00 E8 03 EB 5A`               | 数字界面设置电压 = 10 V（`0x03E8` = 1000 × 10 mV）  |
| 例 3 | `A5 08 01 00 09 5A`               | 打开输出                                            |
| 例 4 | `A5 0F 05 01 15 5A`               | 参数列表 0，关断时间 = 5 分钟                       |
| 例 5 | `A5 1F 05 02 26 5A`               | 参数列表 1，关断时间 = 5 小时                       |

## 5. 快速参考：常用指令速查

| 功能           | 标识帧 | 数据计算方式                   |
|----------------|--------|--------------------------------|
| 设置电压 10 V  | `0x00` | `1000` (10 V / 10 mV)          |
| 设置电流 1 A   | `0x01` | `100` (1 A / 10 mA)            |
| 打开输出       | `0x08` | `1`                            |
| 关闭输出       | `0x08` | `0`                            |

## 6. FastAPI 上位机使用说明

### 6.1 环境要求

- Python >= 3.12
- [uv](https://docs.astral.sh/uv/) 包管理器

### 6.2 项目结构

```
ax_pp300_host/
├── README.md
├── pyproject.toml
├── uv.lock
├── .venv/
└── src/
    └── ax_pp300/
        ├── __init__.py
        ├── protocol.py        # 协议封装（组帧 / 解析）
        ├── serial_client.py   # 串口客户端 + 后台轮询
        └── main.py            # FastAPI 应用入口
```

### 6.3 安装依赖并启动

```bash
# 进入项目目录
cd ax_pp300_host

# 同步虚拟环境（首次运行）
uv sync

# 启动 FastAPI 服务（默认 0.0.0.0:8000）
uv run ax-pp300-host

# 或者使用 uvicorn 直接启动
uv run uvicorn ax_pp300.main:app --host 0.0.0.0 --port 8000 --reload
```

### 6.4 API 一览

| 方法   | 路径            | 说明                     | 请求体示例                                    |
|--------|-----------------|--------------------------|-----------------------------------------------|
| GET    | `/`             | 健康检查                 | —                                             |
| POST   | `/connect`      | 连接串口                 | `{"port": "COM3", "baudrate": 9600}`        |
| POST   | `/disconnect`   | 断开串口                 | —                                             |
| GET    | `/status`       | 获取最新实时数据         | —                                             |
| POST   | `/voltage`      | 设置目标电压             | `{"voltage_mv": 10000}`                     |
| POST   | `/current`      | 设置目标电流             | `{"current_ma": 500}`                       |
| POST   | `/output`       | 打开/关闭输出            | `{"on": true}`                              |
| POST   | `/ovp`          | 设置过压保护             | `{"ovp_mv": 30500}`                         |
| POST   | `/ocp`          | 设置过流保护             | `{"ocp_ma": 10500}`                         |
| POST   | `/raw_command`  | 发送原始指令（调试用）   | `{"identifier": 0, "data": 1000}`           |

> 服务启动后，访问 `http://127.0.0.1:8000/docs` 可直接查看交互式 Swagger 文档并在线调试。

### 6.5 使用示例（PowerShell / curl）

```powershell
# 连接串口
Invoke-RestMethod -Uri http://127.0.0.1:8000/connect -Method POST -ContentType "application/json" -Body '{"port":"COM3","baudrate":9600}'

# 设置电压 12 V
Invoke-RestMethod -Uri http://127.0.0.1:8000/voltage -Method POST -ContentType "application/json" -Body '{"voltage_mv":12000}'

# 设置电流 2 A
Invoke-RestMethod -Uri http://127.0.0.1:8000/current -Method POST -ContentType "application/json" -Body '{"current_ma":2000}'

# 打开输出
Invoke-RestMethod -Uri http://127.0.0.1:8000/output -Method POST -ContentType "application/json" -Body '{"on":true}'

# 查看实时状态
Invoke-RestMethod -Uri http://127.0.0.1:8000/status
```

### 6.6 注意事项

1. **波特率**：协议文档未明确标注波特率，上位机默认使用 **9600**。若通信失败，请尝试 **115200**。
2. **后台轮询**：连接串口后，服务会自动每 **500 ms** 发送一次 `0xFF` 查询指令并缓存最新状态。`/status` 返回的是缓存值，不阻塞串口。
3. **并发安全**：所有串口操作均通过 `threading.Lock` 加锁，保证多线程（如轮询线程 + API 请求）安全。
4. **校验**：`protocol.py` 会自动计算发送帧的校验位，并在收到状态回传时验证校验和。
